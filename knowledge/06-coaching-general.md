# 06 · 带新人通用法：五条原则 + 让成绩被看见 + 请教老员工

> 这篇不讲采购业务，讲「怎么带一个转岗新人」和「新人怎么让自己的工作被看见」。
> 适用对象：带教人（师姐 / 直接领导），也适用新人自己对照着用。所有例子都是采购场景，但方法是通用的。
> 术语第一次出现都带一句白话解释，看不懂的词请直接问，同一个词问十遍答十遍。

## 0. 一句话总纲

带新人 = **把「怎么做」拆成她今天就能做的一步，附上工具，让她自己做完、自己拿到结果、自己去汇报**。
带教人不替做、不替担、不替说——替了，她就永远学不会，成绩也永远不是她的。

## 1. 带新人五条原则

### 1.1 给方案让对方定（两个版本让选，选了就照选的走）

- 新人拿不定主意时，不问「你觉得怎么办」，而是给**两个版本**：「A 版：凑到 MOQ（最小起订量，供应商一次至少接多少）多买 300 只压 2 周库存；B 版：问供应商能不能拼单接小单，晚 2 天。你选哪个？」
- 她选了就照她选的走，**不要**在她选完之后再说「其实我觉得另一个更好」——那等于告诉她「你选也白选」
- 两个版本都要是能落地的方案，不要一个真方案配一个陪跑方案
- 她选错了也让她走完（只要不越红线），出了结果按 §1.5 复盘：只讲下次怎么做

> 为什么：决策肌肉只能自己练。她「定」过的事，才会真正记住判据；你「替她定」的事，下次还是来问你。

### 1.2 选择题代替开放题（是 A 还是 B 一路问）

- 新人说不清情况时，**别**问「到底怎么回事」——她说不清是因为不知道哪些信息重要。改成一路问选择题：
  - 「货是没发，还是发了没到？」→「没发是供应商没排产，还是排了没做完？」→「他给新交期了没有？给了是哪天？」
- 三到五个选择题问完，事实就清楚了，她也顺带学到了「以后要先弄清这几件事」
- 她回答「不知道」是正常的，那一条就变成她的下一步动作：「那你先打电话问清这一条，问完回来」
- 每次问到底之后，把问过的问题串成一张**排查清单**（把「出了事先问哪几个问题」写成固定顺序的表）发给她，下次她自己照着问

### 1.3 一次一件事，并附工具（清单 / 模板 / 表格）

- 一次只教一个动作：今天只讲「怎么算净缺口」，不顺带讲「怎么选供应商」和「怎么开单」
- 每讲一件事，**必须**附一个能直接用的工具：算量给公式表、开单给字段清单、催货给话术模板、汇报给三句话模板
- 不要求新人自己发明流程。「你看着办」「你自己想想怎么做」不是带教，是甩手——流程是带教人给的，新人负责照做和反馈哪里不顺
- 工具给了以后，要求她**照工具走一遍再来找你**，带着填好的表来，而不是带着问题来
- 判断这一步教会了没有：她能不看你、只看表把事做完，就算会了；再教下一件

### 1.4 推不动就换轨，不加力

- 「再催催」「你要强硬一点」都是加力，加力对新人没用——她本来就不知道怎么强硬。换轨是**换一条路**，路要给出具体样子
- 典型换轨：电话催三次供应商没动 → 改**书面**（微信文字 / 邮件，能翻出来的记录）+ **抄送**（CC，让第三方同时看到）对方负责人和自己领导，正文写「X 单承诺 X 日交，已三次电话确认未获答复，请于 X 日前书面回复新交期，否则将启动备选供应商」
- 其它常见换轨：
  - 找仓库对不上数 → 改成把系统截图和送货单照片放一起，请仓库主管拍板（做最终决定）
  - 找生产确认需求确认不下来 → 改成给两个数字让生产选，附「不确认默认按 A 版」的截止时间
  - 问老采购几次没空 → 改成把问题列成三条发文字，请对方有空时打字回，见 §3
- 换轨的判据很简单：**同一个动作做了三次没结果，就换轨，不做第四次**

### 1.5 出了错只讲「下次怎么做」

- 错了就是错了，不复述「你怎么错的」，不追问「你当时为什么没想到」——她比谁都清楚，追问只会让她下次不敢说
- 复盘（把做过的事拿出来对照，找出下次可改的点）固定三句：**事实是什么 / 后果是什么 / 下次在哪一步加一个什么动作**
- 「下次的动作」要落到工具上：加进自查清单一条、跟单表加一列、话术模板改一句——不落到工具上的教训一周就忘
- 她主动来报错的时候，第一句先说「报得对，这个越早说越好」；报错这个行为本身要被鼓励，不然以后出事你最后一个知道
- 涉及**红线**（廉洁、私自承诺、假单据这些碰了直接出局的事）除外——红线要当场讲清楚后果，不是「下次注意」

## 2. 让成绩被看见的三个固定动作

新人最常见的委屈是「我明明做了很多，没人知道」。原因不是做得少，是**没有固定的汇报动作**。汇报不是邀功，是让能替你担责的人掌握信息。三个动作，固定频率，固定格式，做到成习惯。

### 2.1 当天一条消息（发生了什么 + 我做了什么 + 结果）

- 时机：当天下班前，或事情有结果的当下
- 对象：直接领导（一对一，不发群）
- 格式固定三段，一段一句：
  - 发生了什么：「X 供应商 X 料承诺今天到，物流显示滞留 X 地」
  - 我做了什么：「已电话供应商和物流，供应商同意明早改发另一批，生产已知情」
  - 结果：「预计明天 10 点前到，仓库到货预告已改」
- **不要**只报问题不报动作，也不要只报动作不报结果；三段缺一段，领导就要追问，追问就变成了「被盯着」

### 2.2 周五三句话周报

- 每周五下班前发，三句话，多一句都不要，多了没人看：
  1. **本周做成的一件事**：「本周 X 张订单全部按期回签，X 料的重复下单风险在算量时拦住了」
  2. **下周最要盯的一件事**：「下周最要盯 X 供应商 X 料，承诺 X 日到，逾期会影响 X 线」
  3. **需要您拍板的一件事**：「X 料缺口 < MOQ，凑单多压 X 元库存还是拼单晚 2 天，请您定」——没有就写「本周无需拍板事项」
- 三句话周报是**给领导用的**：他转发给他的上级不用改一个字。这就是「让成绩被看见」的真正含义——成绩以能被转发的格式存在
- 周报里的「做成的事」要有数字或单号，不写「工作顺利推进」这类空话

### 2.3 月底一页纸供应商观察

- 每月最后一个工作日，一页纸（一屏能看完），四栏：
  | 供应商 | 本月准交（按承诺日期到货的比例） | 本月问题（一行一件，带日期） | 我的建议（继续 / 观察 / 找备选） |
  |---|---|---|---|
- 数据从订单执行报表和跟单表来，**不要**凭印象写；写不出数据的月份就写「本月 X 单，无异常」
- 这一页纸是月度供应商绩效 QCDS（质量 / 成本 / 交付 / 服务四个维度的打分）里「交付」一项的原始记录，坚持三个月，你就是公司里最清楚供应商交付表现的人

## 3. 请教老员工的三条原则

新人不敢问，是因为怕「问了显得笨」和怕「打扰别人」。这两个怕都能用**方法**解决，不需要靠胆量。

1. **带着具体问题去，不带着「我不懂」去**。「U8 怎么用」没人能答；「到货单参照订单的时候，为什么我这张订单查不到」十秒就能答。问之前自己先试过一遍，说清「我做到哪一步、卡在哪」
2. **一次问一件，问完记下来，同一件事不问第二遍**。记在自己的问题本上（一个 md 或表格：日期 / 问题 / 答案 / 谁说的），下次先翻本子再开口。同一个词你可以问带教人十遍，但对忙着的老员工只问一遍
3. **问完回报结果**。「按您说的改了参照方式，单据出来了，谢谢」——一句回报，下次对方还愿意教。**别**问完就消失，那样第二次就没人理你了

推不动的换轨（对照 §1.4）：当面问两次对方都没空 → 改成文字，把问题列成三条发过去，写「不急，您方便时打字回我就行」；再没回 → 请直接领导帮忙约十分钟。

## 4. 找谁问什么（话术表）

| 找谁 | 问什么 | 不要问什么 |
|---|---|---|
| 系统管理员（管 ERP 账号、权限、基础档案的人） | 权限开通、菜单找不到、新供应商 / 新物料建档、单据弃审（把已审核的单退回可改状态） | 业务判断（「这单该不该下」）——他不负责业务 |
| 老采购（同岗位的老员工） | 公司惯例：走不走请购、税率口径、哪张报表看到货、哪家供应商什么脾气、历史价格在哪查 | 让他替你做决定（「你帮我看看下多少」）——把你算好的数拿去请他挑错 |
| 仓库老员工 | 收货时间窗、卸货预约、点数习惯、入库单谁审核、到货预告发给谁 | 系统里的采购操作——仓库不做采购单 |
| 生产计划（排产、出生产表的人） | 需求日期能不能动、哪个料最急、加单的书面依据、他仓的生产表 | 供应商交期（那是你要回答他的） |
| 直接领导 | 拍板类：超权限加价、凑 MOQ 压库存、启用备选供应商、供应商连续逾期要不要换 | 系统操作细节和日常事务——那是上面四位的事 |

表里的「不要问什么」不是禁令，是省对方时间：问错人两边都尴尬，问对人一句就通。

### 开口第一句（照抄可用）

- 系统管理员：「X 老师打扰一下，我在采购订单界面参照请购单时看不到 X 号单，是权限没开还是我路径不对？我现在走的是 供应链→采购管理→采购订单」
- 老采购：「X 姐 / X 哥，我算了一下 X 料的缺口是 X，在途 X，准备下 X，您帮我看看有没有漏掉的口径？两分钟就行」
- 仓库老员工：「X 师傅，明天 X 供应商大概 X 点到 X 箱，我想提前跟您对一下：几点前能收？要不要先发您送货单照片？」
- 生产计划：「X 老师，X 料供应商最快 X 日到，比生产表晚 X 天，您那边是能调一下排产，还是我走加急？加急要加 X 元」
- 直接领导：「X 总 / X 经理，一件事请您定：X 料缺口 X，方案 A 是……方案 B 是……我倾向 A，因为……您看？」
- 每一句开口话术都是「称呼 + 我做到哪了 + 卡在哪 + 想要什么」四段，照这个结构套，问谁都不虚

## 带教自查清单

- [ ] 这周有没有替她做过决定？有 → 下次改成两个版本让她选
- [ ] 她说不清的时候我问的是选择题还是开放题？
- [ ] 这周教的每件事都附了工具（清单 / 模板 / 表格）吗？
- [ ] 有没有对她说过「再催催」？有 → 补一条具体的换轨路线给她
- [ ] 她出错的时候我第一句说的是「下次怎么做」还是「你怎么错的」？
- [ ] 她的当天消息、周五三句话、月底一页纸，这周都发了吗？没发 → 提醒的是格式，不是「记得汇报」
