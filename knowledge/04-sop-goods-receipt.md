# 04 · 操作2：入库对接 SOP

> 目标：把「已下单、确定某日能到」的货，顺畅交接给仓库接收，并在系统里走完 到货单 → 采购入库单，让库存账和实物一致。
> 责任边界一句话：**采购负责"该到的到没到、对不对"，仓库负责"实收多少、点数入库"**——入库单通常由仓库录入和审核，采购做的是预告、核对与差异处理。

## 第一步：到货预告（提前 1 天，给仓库的交付物）

1. 每天下班前看跟单表 / 采购订单列表，筛出**计划到货日期 = 明天**的订单行
2. 给仓库发**到货计划**（固定格式，微信/邮件皆可，但要留痕）：

   | 订单号 | 供应商 | 物料编码/名称 | 数量 | 预计到达时间 | 备注（急料/需先检） |
   |---|---|---|---|---|---|

3. 供应商已发货的，把物流单号一并给仓库；大件/整车到货提前约卸货时间

> 为什么这步必须做：仓库没预告就收货，只能"来什么收什么"，点错、收错、把 A 供应商的货记到 B 订单上，后面对账全乱。**到货计划是采购与仓库之间的接口协议。**

## 第二步：货到 → 到货单（系统动作）

1. 货到，仓库按送货单初点数量
2. 录到货单：`供应链 → 采购管理 → 到货单 → 增加 → 参照采购订单`
   - **一定参照订单生成**，勾选对应订单行，系统带出物料与价格
   - 实到数量按实点修改（可少于订单量=分批到货；多于订单量见第四步）
   - 审核到货单
3. 启用质检的物料：到货单审核后触发报检，**检验合格才能入库**；不合格走退货/特采，同步通知供应商
4. 谁录到货单按公司分工（确认清单第 4 问）：采购录，则录完通知仓库；仓库录，采购当日核对

## 第三步：入库 → 采购入库单（库存真正增加）

1. 仓库复点上架后录入库单：`供应链 → 库存管理 → 采购入库单 → 参照到货单` 生成，核对仓库、货位、数量
2. **仓库审核入库单** → 库存现存量增加，同时回写采购订单的「累计入库量」——跟踪报表里的入库数据就是从这里来的
3. 采购当日在订单执行报表里核对：该订单行累计入库是否符合预期

> 🔴 常见事故：货实际收了，到货单/入库单没录或没审核 → 账上没库存，生产领不出料，翻仓库才发现货躺在角落。**"实物动，单据动"，当天的货当天单据闭环。**

## 第四步：差异处理（数量对不上时）

| 情况 | 处理 |
|---|---|
| 少到（欠交） | 到货单按实到录；订单行保持开放等补货，跟单表登记欠交量和补货日期；供应商明确不补→手工关闭该订单行 |
| 多到（超交） | 先看公司是否允许超收（系统有超收上限设置）；不收的部分当场拒收退回；要收的先请示，别自作主张 |
| 型号/规格不符 | 整批拒收或走退货流程，当天书面通知供应商，拍照留证 |
| 破损/不良 | 质检判定，不良品走采购退货单，好的部分正常入库；不良明细发供应商要补货或扣款 |

差异不管哪种，**当天同步两边**：仓库（账实一致）+ 供应商（责任归属）。拖过三天，说不清了。

## 入库对接自查清单

- [ ] 明日到货计划已发仓库（提前 1 天）
- [ ] 到货单参照订单生成，实到数量按实点录
- [ ] 需检验的料已报检，合格结论出来才入库
- [ ] 入库单已由仓库审核，订单累计入库数已回写
- [ ] 数量差异当天处理并通知供应商，留痕
- [ ] 跟单表已更新（到货/入库/欠交状态）
