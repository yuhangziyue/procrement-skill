# 05 · 操作3：订单跟踪 SOP（运输 / 到货 / 入库情况）

> 目标：对每一张已下的采购订单，随时答得出三个问题——**货在哪、什么时候到、到了多少入了多少**。
> 工具 = U8 报表（看系统内状态）+ 跟单表（补系统外的物流信息）。两者缺一不可：U8 不记物流单号和催货过程。

## 1. 每日跟单动作（早上 30 分钟）

1. **看订单执行报表**：`采购管理 → 报表 → 采购订单执行情况统计表`（确切名称按 02 §0 回填）
   - 关键列：订单数量 / 累计到货 / 累计入库 / 未到数量 / 计划到货日期
   - 筛「未到数量 > 0」的行，按计划到货日期排序——这就是你的在途全景
2. **三类行动**：

   | 状态 | 判定 | 动作 |
   |---|---|---|
   | 🔴 已逾期 | 计划到货日 < 今天 且 未到量 > 0 | 立即电话供应商问明原因和新交期，更新跟单表，**当天通知生产/计划**（延误影响别人排产，瞒着只会把小事拖成事故） |
   | 🟡 临期 | 3 天内到期 | 催货确认：是否已排产/已发货？要物流单号 |
   | 🟢 未到期 | 距交期 > 3 天 | 长周期物料每周确认一次进度即可 |

3. **核对昨日到货**：昨天预告仓库的到货，今天在报表里看累计入库有没有涨；没涨→查是货没到还是单没录（见 04 第三步事故）

## 2. 跟单表模板（系统外补充，Excel 维护）

U8 管单据数字，跟单表管**过程**：物流、催货记录、责任人。一行一个订单行：

| 订单号 | 供应商 | 物料 | 数量 | 下单日 | 承诺交期 | 发货日 | 物流单号 | 到货量 | 入库量 | 状态 | 跟进记录 |
|---|---|---|---|---|---|---|---|---|---|---|---|

- **状态枚举**：未发货 / 已发货在途 / 部分到货 / 已到待入库 / 已入库完结 / 逾期 / 已关闭
- 跟进记录写「日期+事实」：`9/2 电话张工：已排产，9/5发货` ——将来扯皮时这一列就是证据
- 到货量、入库量两列**以 U8 报表为准回填**，不自己另记一套数——系统是唯一权威源，跟单表只是它的物流补充视图

## 3. 运输情况跟踪

1. 供应商发货当天必须给三样：**物流公司 + 运单号 + 预计到达日**（写进下单要求，养成供应商习惯）
2. 运单号登跟单表，物流官网/快递100 查节点；整车物流直接要司机电话
3. 在途异常（物流停滞 2 天以上）→ 供应商与物流两头催，预计延误就提前改到货预告

## 4. 每周汇总（给上级/生产的交付物）

每周五出一份简报（就从订单执行报表 + 跟单表汇总）：

- 本周到货入库：X 单 X 项，异常 X 项及处理结果
- 在途总览：X 单未完结，其中逾期 X 单（列明供应商、原因、新交期）
- 下周到货计划：给仓库和生产提前排期
- 供应商准交情况：连续逾期的点名——这是月度供应商绩效（QCDS 的 D）的原始数据

## 5. 订单生命周期收尾

- 全部到货入库、数量对平 → 状态改「已入库完结」
- 尾数不再交付（协商取消）→ U8 里**手工关闭订单行**，否则报表里永远挂着一条在途尾巴，越积越多，报表就没人信了
- 月底和财务过一遍：入库未开票清单，催供应商开票（配合暂估冲销）

## 跟踪自查清单

- [ ] 每日早上过一遍订单执行报表，逾期行当天有动作、有通知
- [ ] 跟单表物流列是活的（发货即有单号），不是摆设
- [ ] 到货/入库数字以 U8 为准，不维护第二套账
- [ ] 每周简报按时出，逾期供应商有记录
- [ ] 完结订单及时关闭，报表里没有僵尸在途
