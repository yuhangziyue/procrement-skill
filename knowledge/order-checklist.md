# 下单备忘清单（每张 PO 发出前跑一遍）

> 建于 2026-09-02。配套数据源：供应商供货习惯档案（模板见 `templates/supplier-profile-template.csv`，在小采「资料库」里导入；档案没填完之前，涉及的项逐条电话问）。
> 使用方式：拿到缺料清单后，按 A→E 顺序过；每一步都有明确判据，不凭感觉。

## A. 算量（下多少）

- [ ] 净缺口 = 需求 − 被替代 − 可用现存量 − 采购在途（MRP 已算的核对一遍口径，尤其**在途是否真的还会到**——跟单表里逾期未决的在途不能当有效在途）
- [ ] **多仓核查（调拨优先于采购）**：本仓有缺口的料，先查**其他仓库**的现存量。
  - 他仓可调量 = 他仓现存量 + 他仓采购在途 − **他仓自己生产表的需求** − 他仓安全量——两张生产表都要拿到才能算，只看库存数就调货 = 把别人的产线调停了
  - 可调量 > 0 → 先开**调拨单**覆盖缺口（U8：库存管理 → 调拨业务），剩余缺口才进采购；调拨运输时间照样要过 B 节的排期检验
  - 可调量 ≤ 0 或调拨来不及 → 全量走采购
  - 调拨了要留痕：通知两边仓库 + 需求方，跟单表记「调拨单号/数量/预计到达」
- [ ] 对照档案的 **MOQ**：缺口 < MOQ → 三选一：①凑到 MOQ（多出部分算库存资金占用，量小可接受）②问供应商拼单/加价接小单 ③和生产确认能否合并下次需求
- [ ] 对照 **凑整单位**（扎/箱）：向上取整，把凑整后的量写进订单——不写清楚供应商会替你凑，到货和订单对不上
- [ ] 对照 **单次最大接单量/月产能**：超了→提前和供应商锁排产，或拆单给备用供应商
- [ ] 大单对照 **分批阈值**：会分批的，PO 里写明批次计划（首批比例、各批到货日），每批单独进跟单表

## B. 排期（什么时候到、什么时候下）——本清单的核心

**交期倒推公式**：

```
最晚下单日 = 目标到货日 − 运输时长 − 生产周期 − 接单截止修正(0~1天) − 安全缓冲
```

- [ ] **目标到货日 = 需求日期 − 1~2 天缓冲**，且必须落在**工作日**、仓库**收货时间窗内**（见档案「可送货时间窗」）
  - 算出来落在周六/周日/节假日 → **提前到最近的工作日**（宁早勿晚；提前到周五要确认仓库有位置收）
  - 落在工作日但供应商是下午发次日到 → 确认到达时刻在收货窗内，赶不上就再提前一天
- [ ] 生产周期口径确认：**自然日还是工作日**？工厂周日不生产的，倒推日历要跳过周日
- [ ] 接单截止修正：过了截止时间（如 16:00）下的单算次日接单，+1 天
- [ ] 发货频次修正：不是天天发车的（如周二/四/六），生产完成日要对齐到**下一个发车日**
- [ ] 安全缓冲：常规供应商 +1 天；准交率差的（档案「历史准交率」）+2 天；雨季/大促季再 +1
- [ ] 倒推出的最晚下单日 **≤ 今天** → 常规交期已经来不及：走加急（对照档案加急周期与费用，费用超权限先请示）或立刻反馈生产调整计划——**别下一张注定迟到的单**
- [ ] 跨节假日检查：交期横跨春节/国庆的，按档案「节假日停产安排」整体前置

**示例**：需求日期 9/15（周二）→ 目标到货 9/12（周五，留缓冲且为工作日）→ 运输 2 天 ⇒ 9/10 发货 → 生产 7 天且周日不产（跳过 9/7）⇒ 9/2 须接单 → 今天 9/2 已 17:00 过接单截止 ⇒ 常规来不及，**要么加急要么谈 9/14 一早到**。

## C. 价格与商务

- [ ] 单价与价格档案/最近报价一致；**报价是否过有效期**（档案「报价有效期」），过期先重新确认再下
- [ ] 含税口径、税率与档案一致；订单主体 = 开票主体 = 合同主体
- [ ] 新品/改版：**签样了吗？** 没签样不下批量单；打样周期已加进交期
- [ ] 加急费、运费（超常规批量的运费谁出）、分批产生的额外运费——下单前谈清写进备注
- [ ] 付款条款按档案默认，供应商临时要求改（如要预付）→ 请示后再下

## D. 单据与发出

- [ ] PO 十要素齐：编码/名称/规格、数量+单位、单价+税率、**到货日期（精确到日）**、到货地点、收货时间窗、包装凑整说明、分批计划、质量/单证要求（合格证+检测报告随货）、违约条款
- [ ] 备注栏写清特殊项：加单来源、对应原订单号、加急约定、"到货须为工作日白天并提前一天预告"
- [ ] U8 审核 → 发供应商 → **要书面回签**（回签确认：数量、单价、分批计划、每批到货日）——回签的交期才是跟单表里的承诺交期
- [ ] 整车/大宗到货：按档案「预约卸货」提前约仓库月台

## E. 收尾登记（发出后 10 分钟内做完）

- [ ] 跟单表新增行：订单号、供应商、物料、数量、承诺交期（分批的一批一行）
- [ ] 回复需求方：已下单清单 + 预计到货日 + 交期风险项
- [ ] 给仓库的到货预告排进日历（到货前 1 天发）
- [ ] 拦截/待确认项（停购冲突、超权限加价）单独列出，写明等谁确认、期限

## 常见事故对照（为什么每条都要跑）

| 跳过的项 | 事故 |
|---|---|
| 在途有效性没核 | 在途早已逾期烂尾，账上"有货"实际没有，缺口翻倍 |
| 生产周期口径没问 | "7 天"是工作日，实际 9 个自然日，晚 2 天停线 |
| 到货日落在周六 | 货到门口没人收，退回物流仓，多花一趟运费还晚 3 天 |
| 没对齐发车日 | 生产完成等 2 天才有车，白丢 2 天 |
| 分批计划没写进 PO | 首批只到 20%，生产开线即断料 |
| 没要回签 | 供应商"以为"是下周的单，扯皮无凭据 |
| 改版没签样 | 整批 5 万只腰封文字印错，全数报废谁承担吵一个月 |
