# 01 · 采购专员技能树与基本常识

> 目标：一名新采购专员照这张树补课，能在两周内独立接活。按「必须会 → 应该会 → 加分项」排序。

## 0. 角色一句话

采购专员 = **把公司要的东西，以合适的价格、合格的质量、准确的数量，在需要的时间送到需要的地方**——这就是采购的 5R 原则：
适价（Right Price）、适质（Right Quality）、适量（Right Quantity）、适时（Right Time）、适地（Right Place）。
每一个日常动作（下单、催货、对数）都是在守其中某一个 R。

## 1. 必须会（第一个月的基本盘）

### 1.1 采购全流程（闭环七步）

```
需求确认 → 询价比价 → 定供应商 → 下采购订单(PO) → 跟单催货 → 收货入库 → 对账付款
   ↑生产/计划给     ↑至少3家       ↑价格+交期+账期      ↑书面确认       ↑每日看        ↑与仓库交接     ↑与财务交接
```

- 每一步都要**留痕**：需求要有生产表/请购单，价格要有报价单，下单要有供应商回签，收货要有入库单。
- 口诀：**无单不采，无签不认，无验不收**。

### 1.2 订单要素（一张合格 PO 必须有的字段）

物料编码+名称+规格型号 / 数量+单位 / 单价+税率（国内货物通常 13%）+ 含税与否 /
**交货日期** / 交货地点 / 付款条款（预付 / 货到付款 / 月结 30·60·90）/ 质量标准或参照样品 / 违约条款。
其中**交期和付款条款**是最容易被口头带过、事后扯皮的两项——必须落在书面。

### 1.3 单据与对数常识

- 三个数必须对得上：**订单数量 = 到货数量 = 入库数量**（差异要有说法：欠交补货 / 超交退回或协商收下）
- 付款前的**三单匹配**：采购订单、入库单、发票三者一致才付款——这是财务风控底线，也是保护采购自己的证据链
- 发票：增值税专用发票，票面单价×数量×税率要与订单一致；供应商名称必须与合同主体一致

### 1.4 内部协作界面（采购和谁打交道、交付什么）

| 对方 | 对方给你 | 你给对方 |
|---|---|---|
| 生产/计划 | 生产表、缺料清单、加单需求 | 交期承诺、到货预告、延期预警 |
| 仓库 | 实收数量、入库单 | 到货计划（什么货、哪天到、多少） |
| 品质 | 检验结果 | 到货批次信息、不良品与供应商的处理结论 |
| 财务 | 付款执行 | 对账单、发票、三单匹配的凭据 |

## 2. 应该会（第二、三个月上手）

### 2.1 询比价与议价

- **至少 3 家比价**是行规，比的不只是单价：价格、交期、起订量(MOQ)、账期、运费谁出、含税与否——折成**总成本(TCO)**再比
- 议价筹码：批量、账期换价格、长期合作承诺、竞品报价
- 常识：报价有效期通常 15~30 天；原材料波动大的品类（铜、塑料粒子、纸）要约定调价机制

### 2.2 供应商管理入门

- 建**供应商档案**：营业执照、开票信息、联系人、银行账户、报价单、合作历史
- 绩效四维 **QCDS**：质量（来料合格率）、成本（价格水平）、交付（准交率）、服务（响应速度）
- 每类关键物料至少**一主一备**两家供应商——单一供应商断供就是生产停线

### 2.3 库存与需求常识

- 看得懂 BOM（物料清单）：生产 100 台成品各需要什么料、多少
- 下单量 = 需求量 −（可用库存 + 在途量）+ 安全库存缺口——**先查库存和在途再下单**，重复下单是新手最常见事故
- 交期倒推：需求日期 − 供应商生产周期 − 运输时间 = 最晚下单日

## 3. 加分项（半年后拉开差距）

- 成本分析：懂供应商的料工费构成，议价时能拆价
- 合同风险：违约金、质保期、知识产权、独家条款
- 数据能力：用 Excel/报表做准交率、价格趋势、库存周转分析
- 品类专业知识：懂自己买的东西（材质、工艺、行情）——采购的专业壁垒最终在品类

## 4. 红线（一条都不能碰）

1. **廉洁**：不收供应商好处（回扣、礼品、宴请超标）——这是行业第一高压线，公司抓到直接开除+追责
2. **不私自承诺**：付款、价格、免检等承诺必须在授权范围内，超出的先请示
3. **不飞单**：不绕过公司流程私下指定供应商
4. **信息保密**：底价、竞品报价、公司需求计划不外泄
5. **单据真实**：不倒签日期、不补假单据

## 5. 常用术语速查

| 术语 | 意思 |
|---|---|
| PO | Purchase Order，采购订单 |
| PR | Purchase Requisition，请购单/采购申请 |
| MOQ | 最小起订量 |
| L/T (Lead Time) | 交货周期（下单到到货） |
| 月结30 | 当月对账，次月30天内付款 |
| 暂估入库 | 货到票未到，先按订单价入库入账，票到后冲回调整 |
| 在途 | 已下单未到货的量 |
| 准交率 | 按约定日期交货的订单占比 |
| 三单匹配 | 订单、入库单、发票一致才付款 |
